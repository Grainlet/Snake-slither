# Survive-The-Snake
Survive The Snake is a game inspired from the famouse slither game where the main objective is to eat food, grow the snake and engulf other snakes to become the biggest snake,
but Survive The Snake is a bit different, you let your opponent (INFAMOUS RED SNAKE) train on it's own, longer you train it, the better it becomes at beating you.
The Player's job is to defeat the "Red Snake" by maneuvering and attacking the snake.
